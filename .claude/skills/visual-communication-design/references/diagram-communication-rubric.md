# Diagram Communication Critique Rubric

Score every diagram style, symbol kit, or rendered artifact from `1` to `5` on
each dimension (target: **>= 4.5 average**, zero dimensions below `4` to claim
Figma/Excalidraw parity).

| # | Dimension | 1–2 (Auto-Generated / Slop) | 3 (Acceptable / Functional) | 4–5 (Figma / Excalidraw Parity) |
| --- | --- | --- | --- | --- |
| 1 | **5-Second Squint Readability** | Flat visual noise; unclear start, flow, or groupings | Main blocks visible, but grouping and flow compete | Entry point, zones, primary spine, and focal nodes read effortlessly in < 2 seconds |
| 2 | **Chromatic Restraint** | Rainbow pastel fills + heavy dark borders on every box | Reduced palette but uneven perceptual brightness | 60-30-10 discipline; neutral surfaces with purposeful semantic accents |
| 3 | **Typographic Hierarchy** | One uniform font size/weight everywhere | Minor color differentiation only | Clear 3-tier scale (Title / Meta Badge / Description) with tight, legible rhythm |
| 4 | **Symbol & Icon Clarity** | Text crammed inside clipart outlines or ambiguous bare boxes | Recognizable shapes but uneven stroke weights | Cohesive icon kit inside balanced squircle badges or crisp geometric silhouettes |
| 5 | **Container & Zone Framing** | Weak dashed wireframe boxes with floating titles | Lightly tinted boxes with basic top text | Layered surface depth (L0→L1→L2) with anchored header pills and clean nesting |
| 6 | **Edge & Label Rhythm** | Cluttered raw lines; unpadded opaque text boxes slicing wires | Clean orthogonal routing with basic white boxes | Clear flow hierarchy (sync/async/data/error), rounded elbows, pill-framed labels |
| 7 | **Figure-Ground & Depth** | Flat plane; cards, zones, and canvas blur together | Distinct borders but stiff/clinical feel | Subtle multi-layer elevation (light) or luminance steps (dark); calm breathing room |
| 8 | **Notation Idiomatic Fit** | One generic theme forced across ERD, BPMN, C4, and Sketch | Slight shape tweaks per diagram type | Each diagram type honors its domain conventions while feeling unmistakably one family |

## Critique Output Format

When reviewing any diagram or style update:

1. **Verdict & Score Table** (8 dimensions + overall mean).
2. **Top 3 Highest-Leverage Visual Defects** (ranked by reader comprehension impact).
3. **Concrete Token / Geometry / SVG Fixes** (exact hex/px/path changes, never vague "make it prettier" advice).
4. **Before/After Verification Checklist** (contrast, true-font alignment, dark-mode parity, zero layout-contract violations).
