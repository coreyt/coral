# Development Documents

The active release is **0.2.12** ([launch plan](releases/0.2.12/plan.md)),
launching Coral as a clean public open-source repository.

## Current authorities

- [`requirements.md`](requirements.md) and [`requirements/`](requirements/) —
  active product and quality requirements.
- [`ARCHITECTURE.md`](ARCHITECTURE.md) — workspace architecture and package
  boundaries.
- [`DOMAIN.md`](DOMAIN.md) — diagramming domain concepts and terminology.
- [`ROADMAP.md`](ROADMAP.md) — shipped milestones and planned future work.
- [`designs/`](designs/) — durable technical design specifications, including
  [language design and evolution](designs/language-design-and-evolution.md) and
  the [visual rendering specification](designs/visual-rendering-specification.md).
- [`documentation-style.md`](documentation-style.md) — documentation authoring
  and profile rules.
- [`docs-feature-map.json`](docs-feature-map.json) — documentation coverage
  mapping verified by `npm run check:docs`.
- [`release-policy.json`](release-policy.json) — machine-checked CI, Pages,
  and release workflow policy.

Historical R&D experiments, archives, and pre-public release evidence
(`0.2.2`–`0.2.11`) are preserved separately outside this public repository.
