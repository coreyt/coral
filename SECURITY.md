# Security Policy

## Supported versions

Security fixes are maintained on the current `0.2.x` release line.

| Version | Supported |
| --- | --- |
| `0.2.x` (latest) | Yes |
| `< 0.2.12` | No |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues or
discussions.

Use
[GitHub Security Advisories](https://github.com/coreyt/coral/security/advisories/new)
to report vulnerabilities privately to the maintainers. Include:

- A clear description of the vulnerability and affected package(s) or editor
  surface.
- Minimal reproduction steps, Coral DSL input, or proof-of-concept payload.
- Impact assessment (for example SVG/HTML sanitization bypass, prototype
  pollution, ReDoS, or dependency exposure).

## Response timeline

- **Acknowledgement:** within 3 business days.
- **Triage and remediation plan:** within 7 business days for confirmed issues.
- **Coordinated disclosure:** once a fix is verified and published, a security
  advisory and changelog entry will be released.
