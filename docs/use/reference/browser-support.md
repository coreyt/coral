# Browser support

Support boundaries for using Coral 0.2.15.

| Environment | Status | Boundary |
| --- | --- | --- |
| Chrome desktop | Supported | Desktop web application on Linux, Windows, and macOS |
| Edge desktop | Experimental | May work; no support claim is made |
| Safari desktop | Experimental | May work; no support claim is made |
| Firefox desktop | Experimental | Web application only; no support claim is made |
| Mobile browsers | Not supported | Desktop layout only |
| Network unavailable | Not supported | Reconnect and reload |

Coral is an online-hosted application. It offers no installation or offline
application shell.

Chrome is the supported desktop browser. Edge, Safari, and Firefox are
experimental.

Coral supports desktop browsers only. Mobile browsers are not supported.

The [on-device editing model](../explain/on-device-editing-model.md) is now
available as an experimental release, and its performance is alpha-level.
Composer voice input is not available.
Accessibility support remains experimental. Decision-edge routing also
recognizes English labels. Exported non-Latin labels can be mis-sized; inspect
the exported graphic.
