# Preferences

Browser-local editor choices; document-owned layout and font settings are
excluded.

| Name | Values | Default | Effect |
| --- | --- | --- | --- |
| Theme | System, Light, Dark | System | Application appearance |
| Show minimap | On, Off | On | Shows the canvas minimap |
| Show controls | On, Off | On | Shows complete canvas controls |
| Fit view on load | On, Off | On | Fits opened content |
| Entity highlighting | On, Off | Off | Highlights DSL entities |
| Reset workspace layout | Action | — | Restores panel sizes |
| Default notation | Installed notations | Flowchart | New diagrams |
| Default layout | Layout presets | Flowchart | New-diagram layout preset |
| On-device editing model (experimental) | On, Off | Off | Shows the AI tab; see [the on-device editing model](../explain/on-device-editing-model.md) |

Coral has no AI provider, transcript or voice settings.

Workspace preferences and user preferences stay in this browser. A saved Coral
document owns its own notation, layout, positions, and document settings.
