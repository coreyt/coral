# Keyboard shortcuts

Editor chords and palette commands; browser and operating-system shortcuts are
excluded.

| Chord | Action | Scope |
| --- | --- | --- |
| `Ctrl/Command+K` | Command palette | Application |
| `Ctrl/Command+Alt+N` | Create Node | Document |
| `Ctrl/Command+Alt+E` | Create Edge | Document |
| `Ctrl/Command+S` | Save | Document |
| `Ctrl/Command+Z` | Undo | Active editing scope |
| `Ctrl/Command+Shift+Z` | Redo | Active editing scope |
| `Ctrl+Y` | Redo (Windows convention) | Active editing scope |
| `Ctrl/Command+Shift+L` | Reflow layout | Diagram |
| `Ctrl/Command+,` | Preferences | Application |
| `Escape`, then `Tab` | Leave source forward | DSL editor |
| `Escape`, then `Shift+Tab` | Leave source backward | DSL editor |

AltGr character entry and input-method composition do not trigger application
shortcuts. Native text fields retain their own undo and redo.

| Palette command | Category |
| --- | --- |
| Create Node, Create Edge | Edit |
| Reflow Layout, Undo, Redo | Layout |
| Save Document and five Export commands | File |
| Switch to Mermaid, Switch to Coral DSL | Editor |
| Five Notation commands | View |
| Show or Hide Inspector, Preferences | View |
| Welcome and Examples, Help, About Coral | Help |
