# AI generation availability

The on-device editing model is now available as an experimental release,
and its performance is alpha-level. It proposes edits to the open flowchart
from a short English request; see
[How to edit with the on-device model](edit-with-the-on-device-model.md).
Coral has no AI conversation, provider settings or AI Fix action.

::: info
The on-device editing model is experimental. It requires a network
connection to download. Its requests run in this browser and are not sent
anywhere.
:::

Use the source editor, supported canvas actions and Reflow to edit diagrams.
Supported Mermaid conversion uses deterministic parsing and writing
without an AI provider. See [conversion support](../reference/conversion-support.md)
for the current subsets.
