# How to use the hosted web app

Open Coral in a supported desktop browser. Coral 0.2.6 is an online-hosted
application; it does not offer installation or an offline application shell.

1. Open the release URL supplied by the Coral host. When moving from 0.2.5,
   the first visit from your existing bookmark still shows 0.2.5 and removes
   only Coral's old offline data. Save your work, then reload to reach the
   hosted app. Or open the versioned `/coral/?online=0.2.6` transition URL
   once.
2. Confirm the release identity shown in the application matches the version
   you intended to use.
3. Open or create a Coral document. Documents remain user-owned: save files
   explicitly and use browser-local recovery only as a safety net.
4. Keep the application online while using it. If the network is unavailable,
   reconnect and reload the hosted application; do not rely on an installed or
   cached Coral shell.
5. Save current work before accepting a browser reload or navigating away.

Coral supports desktop browsers only. Mobile browsers are not supported.

## Result

Coral is open as the current hosted application and local document ownership
remains explicit.
