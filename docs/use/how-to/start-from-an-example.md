# How to start from an example

Open a bundled Coral source example as a new local document. The original
example text stays unchanged.

1. Open **Command palette** > **Welcome and Examples**. The Welcome dialog
   lists the bundled examples.
2. Select one example. The Coral source appears in the editor and its diagram
   appears on the canvas.
3. Edit the Coral source, then save. Some canvas gestures can make verified
   source edits, such as inline labels and semantic-port connections. The
   saved document keeps your exact Coral text; the bundled example stays
   unchanged.

Browse previews and download source, documents or SVG from the
[example gallery](https://coreyt.github.io/coral/examples/). Each
**Open in Coral** link selects the matching catalog edition in Welcome. Choose
**Open requested example** there to use a local copy. An unavailable edition
leaves your current work unchanged.

## Result

The selected example is an editable Coral document with its original diagram
type. Save and reopen preserve its authored source.
