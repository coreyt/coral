# How to use Coral with the keyboard

Reach the primary editing tasks and leave the DSL editor without a pointer.

1. Press `Ctrl/Command+K` to open **Command palette**. Focus moves into the
   command search field and the command list is available by keyboard.
2. Choose **Create Node**, **Create Edge**, or **Reflow Layout**. The selected
   command opens its dialog or updates the canvas.
3. In the DSL editor, press `Escape`, then `Tab` or `Shift+Tab`. Focus leaves
   the editor in the chosen direction.
4. Use arrow keys on focused separators such as **Resize source**. The named
   region changes size and reports its effective value.
5. Close a modal dialog with `Escape`. Focus returns to the control that opened
   it.

## Result

The document can be created, edited, laid out, and saved with keyboard controls.
