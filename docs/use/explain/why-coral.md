# Why Coral

Coral keeps authored meaning, current geometry, and shareable output in one
local-first diagram workflow.

## Text and canvas stay connected

Coral DSL gives a reviewable source form while the canvas supports direct
selection, position, connection, and property edits. A committed change updates
one document rather than two competing copies.

## Meaning survives layout

Exact positions, pins, constraints, routes, and waypoints are authored intent.
Reflow computes verified geometry without promoting computed-only positions
into source or silently dropping authored spatial meaning.

## Local work is the default

Documents, recovery data and settings remain in the browser or files you
save. The [on-device editing model](on-device-editing-model.md) is now
available as an experimental release, and its performance is alpha-level.
Composer voice input is not available.

## Boundaries are visible

Conversion, unsupported layout and export refusal produce
diagnostics. Coral retains the last verified diagram rather than hiding a
partial failure.
