# Historical clean-room proposal for `libavoided-js`

Historical boundary for a pre-publication external-dependency proposal.

| Record | Authority |
| --- | --- |
| Former proposal | History only; not an active Coral procedure |

This file preserves a process proposal written before `libavoided-js` was
published. It is not an active Coral procedure, compliance checklist, or claim
that the proposed steps were completed.

Coral does not contain or develop `libavoided-js`: it consumes the public,
exact dependency `libavoided-js@0.1.2`. The previously named in-repository
`packages/libavoided-js/**`, `spec/**`, and `docs/compliance/**` paths do not
exist here, and Coral CI must not pretend to enforce records at those paths.
Provenance and development-process evidence for that external package belongs
with its actual source and maintainers. This repository currently names no
verified authoritative provenance location for it.

Accordingly, this record establishes neither successful clean-room completion
nor a provenance failure. Any future Coral policy that depends on such evidence
must first identify and review attributable records from the external package;
until then, dependency integrity, licensing, package contents, and Coral's own
adapter behavior are the locally verifiable release gates.

The former unchecked proposal is recoverable from repository history.
