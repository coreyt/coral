By the end of this flow, a user has entered a brand new password through the New Password Form, but several steps happen first. The process starts when the User submits an email address to the Password Reset Request form. That form turns around and requests a reset token from the Auth Service, which stores the generated token in the Reset Token Store. The Auth Service also triggers the Email Service to send a reset email, which delivers the reset link back to the User. Only after receiving that link does the User submit a new password to the New Password Form.
