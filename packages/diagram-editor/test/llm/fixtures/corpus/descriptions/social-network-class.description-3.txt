Enumerating the components first, then their connections. Components: User, Profile, Post, Comment, Like, Friendship, Message, Conversation, Group, GroupMembership, Notification, Photo, Album, NewsFeed — fourteen classes in all. Connections: User is composed of Profile; User creates Post; Post is composed of both Comment and Like; User writes Comment and gives Like directly as well; User initiates Friendship, and Friendship connects back to User; User sends Message, and Message belongs to Conversation, while User also participates in Conversation independently; User holds GroupMembership, and GroupMembership is a membership in Group; User receives Notification; User is composed of Album, and Album is in turn composed of Photo; and User views NewsFeed. That accounts for all seventeen relationships in the diagram.
