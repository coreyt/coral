Three participants take part: Client, Server, and Logger. In order, the messages are: the Client sends "ping" to the Server; the Server replies with "pong" to the Client; the Server sends "record ping-pong latency" to the Logger; the Client again sends "ping" to the Server; the Server again replies with "pong" to the Client; and the Server again sends "record ping-pong latency" to the Logger.
