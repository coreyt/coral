This class diagram models a library system with eight classes: Library, Branch, Catalog, Book, Author, Member, Loan, and Librarian. Library has name and address fields and is composed of Branch, which has a location field. Branch is composed of Catalog, which has a search() method. Catalog aggregates Book, which has title and isbn fields. Book has a "written by" association pointing to Author, which has a name field. Member has name and memberId fields and has a "borrows" association pointing to Loan, which has a dueDate field and a returnBook() method. Loan has a "references" association pointing back to Book. Librarian has employeeId and checkOut() members and has a "processes" association pointing to Loan. Branch also aggregates Librarian.
