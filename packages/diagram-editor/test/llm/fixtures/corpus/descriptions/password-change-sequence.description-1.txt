This sequence diagram involves four participants: User, WebApp, AuthService, and UserDB. The User submits their current and new password to the WebApp. The WebApp requests a password change from the AuthService. The AuthService verifies the current password hash with the UserDB. The UserDB replies that the password hash is valid. The AuthService then stores the new password hash in the UserDB. The AuthService sends a password changed confirmation back to the WebApp. Finally, the WebApp displays a success message to the User.
