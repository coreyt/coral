This diagram models an order fulfillment network with sixteen components. It begins when the Customer places an order through the Storefront App. The Storefront App submits the order to the Order Service. The Order Service checks stock with the Inventory Service, which reads and writes stock levels in the Warehouse Database. The Order Service also charges the customer through the Payment Service, which screens the transaction with the Fraud Check Service and processes the payment through the Payment Gateway. Separately, the Order Service sends a fulfillment request to the Warehouse Management System, which assigns a pick task to the Pick and Pack Station. Once the package is ready, the Pick and Pack Station hands off to the Shipping Service, which books a shipment with the Carrier API. The Carrier API provides a tracking number to the Tracking Service, which sends updates to the Notification Service; the Order Service also sends its own confirmation directly to the Notification Service. Independently, the Customer can request a return through the Returns Service, which approves a refund through the Refund Service. The Refund Service issues the refund via the Payment Gateway, and the Returns Service also restocks the item back through the Inventory Service.
