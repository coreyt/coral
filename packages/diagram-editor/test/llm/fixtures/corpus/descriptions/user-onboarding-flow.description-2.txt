Nine components make up this onboarding flow: New User, Signup Form, Auth Service, User Database, Email Verification Service, Profile Setup Wizard, Welcome Email Service, User Dashboard, and Analytics Service. The connections: the New User submits the Signup Form; the Signup Form asks the Auth Service to create an account; the Auth Service stores credentials in the User Database and sends a verification email through the Email Verification Service; the Email Verification Service delivers a verification link to the New User; the New User clicks that link, which goes back to the Auth Service; the Auth Service redirects to the Profile Setup Wizard; the Profile Setup Wizard saves profile data to the User Database and triggers the Welcome Email Service; the Welcome Email Service redirects to the User Dashboard; and the User Dashboard logs activity to the Analytics Service.
