This social network diagram has fourteen classes: User, Profile, Post, Comment, Like, Friendship, Message, Conversation, Group, GroupMembership, Notification, Photo, Album, and NewsFeed. A User is composed of a Profile. A User creates a Post. A Post is composed of Comment instances and separately composed of Like instances. A User writes a Comment, and a User gives a Like. A User initiates a Friendship, and a Friendship connects to a User. A User sends a Message, and a Message belongs to a Conversation. A User also participates in a Conversation directly. A User holds a GroupMembership, and a GroupMembership is a membership in a Group. A User receives a Notification. A User is composed of Album instances, and an Album is composed of Photo instances. Finally, a User views a NewsFeed.
