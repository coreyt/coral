This banking system diagram has fourteen classes: Bank, Branch, Account, CheckingAccount, SavingsAccount, Customer, Transaction, Card, Loan, LoanApplication, Teller, ATM, Statement, and InterestRate. A Bank is composed of Branch instances. Each Branch aggregates Teller instances and separately aggregates ATM instances. A Customer owns an Account. Account is a parent class that CheckingAccount inherits from, and Account is also the parent class that SavingsAccount inherits from. Account is composed of Transaction instances. A Customer holds a Card, and a Card is linked to an Account. A Customer submits a LoanApplication, and a LoanApplication is approved as a Loan. A Loan is disbursed to a Customer. An Account generates a Statement. A SavingsAccount accrues an InterestRate. Both a Teller and an ATM process a Transaction.
