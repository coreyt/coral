Eight classes make up this system: Library, Branch, Catalog, Book, Author, Member, Loan, and Librarian. Library carries name and address fields. Branch carries a location field. Catalog carries a search() method. Book carries title and isbn fields. Author carries a name field. Member carries name and memberId fields. Loan carries a dueDate field and a returnBook() method. Librarian carries an employeeId field and a checkOut() method. As for connections: Library is composed of Branch, Branch is composed of Catalog, Catalog aggregates Book, Book is written by Author, Member borrows Loan, Loan references Book, Librarian processes Loan, and Branch aggregates Librarian.
