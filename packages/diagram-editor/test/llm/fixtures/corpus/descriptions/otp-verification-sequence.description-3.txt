This exchange ends with the App learning that a one-time passcode is valid. It starts when the User enters a phone number into the App, which requests an OTP from the AuthService. The AuthService sends the OTP code to the SMSGateway, which delivers it via SMS to the User. The User then enters that OTP code back into the App, which asks the AuthService to verify it, and the AuthService confirms back to the App that the OTP is valid.
