This diagram models a user onboarding flow with nine components. The New User submits the Signup Form, which asks the Auth Service to create an account. The Auth Service stores credentials in the User Database and sends a verification email through the Email Verification Service. The Email Verification Service delivers a verification link back to the New User, who clicks it, sending the New User back to the Auth Service. The Auth Service then redirects to the Profile Setup Wizard, which saves profile data to the User Database and triggers the Welcome Email Service. The Welcome Email Service redirects the user to the User Dashboard, and the User Dashboard logs activity to the Analytics Service.
