Seven components are involved: Viewer, Client Player, Manifest Service, License Server, CDN Edge Node, Origin Server, and Analytics Service. The Viewer connects only to the Player, pressing play and later receiving a rendered video frame. The Player is the hub, connecting to every other component: it requests the manifest from the Manifest Service (getting available renditions back), requests a DRM license from the License Server (getting license granted back), requests segments twice from the CDN Edge Node and gets segment data back both times, first as a cache miss and second as a cache hit, and sends three separate reports to the Analytics Service — playback started, a buffering event, and playback progress. The CDN Edge Node also connects to the Origin Server: on the cache-miss request it fetches the segment from the Origin Server and receives the segment data in reply, before passing that segment data on to the Player.
