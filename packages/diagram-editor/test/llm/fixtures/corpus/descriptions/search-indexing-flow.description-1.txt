This diagram models a search indexing and query flow with nine components. The Crawler Service fetches documents from the Content Store and sends the raw content to the Parser Service. The Parser Service extracts text and passes it to the Tokenizer, which emits tokens to the Index Builder. The Index Builder writes the index into the Search Index. On the query side, the User submits a search query to the Query Service, which looks up terms in the Search Index. The Search Index returns matches to the Ranking Service, which returns ranked results back to the Query Service. Finally, the Query Service displays the results to the User.
