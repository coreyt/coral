Eleven parts make up this system: a Client App, an API Gateway, an Auth Service, a User Service, an Order Service, a Payment Service, an Inventory Service, a Notification Service, a User Database, an Order Database, and the external Stripe API. The connections are as follows. The Client App reaches the API Gateway with an HTTPS request. The API Gateway talks to the Auth Service to authenticate, to the User Service to route user requests, and to the Order Service to route order requests. The Auth Service reaches into the User Database to verify credentials, and separately the User Service reaches the User Database to read and write profile data. The Order Service writes to the Order Database to persist each order, calls the Inventory Service to check stock, calls the Payment Service to charge the customer, and calls the Notification Service to send a confirmation. The Payment Service, in turn, calls out to the Stripe API to process the payment.
