This is a login request sequence involving four participants: a Client, a Web Server, an Auth Service, and a Database. The Client sends a "POST /login (username, password)" request to the Web Server. The Web Server calls the Auth Service with "validateCredentials(username, password)". The Auth Service queries the Database with "SELECT user WHERE username = ?", and the Database replies with the "user record". The Auth Service then performs a self-check labeled "verify password hash". From here the flow branches on whether the credentials are valid. On the valid path, the Auth Service replies to the Web Server with an "auth token", and the Web Server replies to the Client with "200 OK + session token". On the invalid path, the Auth Service instead replies to the Web Server with "authentication failed", and the Web Server replies to the Client with "401 Unauthorized".
