There are six components here: User, File Upload Form, Upload Service, Virus Scanner Service, Object Storage, and Notification Service. Tracing the connections in order: the User submits a selected file to the File Upload Form; the File Upload Form sends the file onward to the Upload Service; the Upload Service requests a malware scan from the Virus Scanner Service; the Virus Scanner Service replies that the scan passed; the Upload Service writes the file to Object Storage; and the Upload Service notifies the Notification Service that the upload is complete.
