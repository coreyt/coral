This diagram shows a file upload flow with six components: a User, a File Upload Form, an Upload Service, a Virus Scanner Service, Object Storage, and a Notification Service. The User selects a file and submits it to the File Upload Form. The File Upload Form sends the file to the Upload Service. The Upload Service asks the Virus Scanner Service to scan the file for malware, and the Virus Scanner Service reports back to the Upload Service that the scan passed. The Upload Service then stores the file in Object Storage and sends an upload complete notice to the Notification Service.
