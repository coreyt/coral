Ultimately a logged-in user either lands on the Dashboard or gets bounced back to try again. Working backward: the Dashboard is only reached from the "Valid Credentials?" check, taken on the "yes" path. The same check also has a "no" path that goes to an Error Message, and that Error Message doesn't dead-end — it sends the person back to the Login Form with a "retry" connection so they can try again. The Login Form itself receives the credential check request only after the User first submits their credentials to it.
