This diagram traces a chat message from sender to recipient through six participants: a Sender, a Chat Service, a Message Queue, a Presence Service, a Push Notification Service, and a Recipient Device. The Sender sends a message to the Chat Service. The Chat Service enqueues the message with the Message Queue, then asks the Presence Service to check the recipient's status. The Presence Service replies that the recipient is offline. Because of that, the Chat Service asks the Push Notification Service to send a push notification, and the Push Notification Service confirms the notification is queued. Separately, the Message Queue delivers the message to the Recipient Device, which sends back a delivery acknowledgment to the Message Queue. The Message Queue then tells the Chat Service the message was delivered, and the Chat Service finally sends a delivery receipt back to the Sender.
