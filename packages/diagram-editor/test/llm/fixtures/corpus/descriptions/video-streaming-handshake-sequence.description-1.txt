This diagram shows a video streaming startup handshake across seven participants: a Viewer, a Client Player, a Manifest Service, a License Server, a CDN Edge Node, an Origin Server, and an Analytics Service. The Viewer presses play in the Player. The Player requests a manifest from the Manifest Service, which replies with the manifest listing available renditions. The Player then requests a DRM license from the License Server, which replies that the license is granted. The Player requests a video segment from the CDN Edge Node; since this is a cache miss, the CDN Edge Node fetches the segment from the Origin Server, which returns the segment data, and the CDN Edge Node passes that segment data back to the Player. The Player reports to the Analytics Service that playback has started. The Player then requests the next segment from the CDN Edge Node, which this time returns the segment data as a cache hit. The Player reports a buffering event to the Analytics Service, renders a video frame back to the Viewer, and reports playback progress to the Analytics Service.
