A Canvas sits at the top of this diagram, aggregating Shape objects (it can hold many Shapes without owning them, and has an addShape() method). Shape itself is the base class, with a color field and an area() method, and it has three subclasses that inherit from it: Circle, which adds a radius field and its own area() implementation; Rectangle, which adds width and height fields and its own area() implementation; and Triangle, which adds base and height fields and its own area() implementation.
