Four participants are involved: User, WebApp, AuthService, and UserDB. In sequence: User to WebApp, submitting the current and new password; WebApp to AuthService, requesting a password change; AuthService to UserDB, verifying the current password hash; UserDB to AuthService, confirming the password hash is valid; AuthService to UserDB, storing the new password hash; AuthService to WebApp, confirming the password was changed; and WebApp to User, displaying a success message.
