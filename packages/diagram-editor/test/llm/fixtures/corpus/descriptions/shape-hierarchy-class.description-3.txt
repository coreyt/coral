Five classes make up this diagram: Shape, Circle, Rectangle, Triangle, and Canvas. Shape carries a color field and an area() method. Circle carries a radius field and its own area() method. Rectangle carries width and height fields and its own area() method. Triangle carries base and height fields and its own area() method. Canvas carries an addShape() method. As for connections: Circle inherits from Shape, Rectangle inherits from Shape, Triangle inherits from Shape, and Canvas aggregates Shape.
