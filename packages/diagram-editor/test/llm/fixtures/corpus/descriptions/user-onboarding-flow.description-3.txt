By the end of this flow, a new user lands on their Dashboard with activity already being tracked in the Analytics Service. It all starts when the New User submits the Signup Form, which has the Auth Service create an account. The Auth Service stores the new credentials in the User Database and has the Email Verification Service send out a verification email, which delivers a link back to the New User. Clicking that link sends the New User back to the Auth Service, which redirects into the Profile Setup Wizard. The wizard saves profile data into the User Database and triggers the Welcome Email Service, which redirects the user to the User Dashboard, and the Dashboard, in turn, logs activity to the Analytics Service.
