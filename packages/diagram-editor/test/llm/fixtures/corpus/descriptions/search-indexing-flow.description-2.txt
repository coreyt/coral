Nine components appear here: Content Store, Crawler Service, Parser Service, Tokenizer, Index Builder, Search Index, User, Query Service, and Ranking Service. The connections: the Crawler Service fetches documents from the Content Store; the Crawler Service sends the raw content to the Parser Service; the Parser Service extracts text and sends it to the Tokenizer; the Tokenizer emits tokens to the Index Builder; the Index Builder writes the index to the Search Index; the User submits a search query to the Query Service; the Query Service looks up terms in the Search Index; the Search Index returns matches to the Ranking Service; the Ranking Service returns ranked results to the Query Service; and the Query Service displays the results to the User.
