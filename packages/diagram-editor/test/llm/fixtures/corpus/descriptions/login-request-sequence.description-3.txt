There are two possible outcomes to this login sequence, both starting the same way. A Client posts login credentials to a Web Server ("POST /login (username, password)"), which asks an Auth Service to validate them ("validateCredentials(username, password)"). The Auth Service looks the user up in a Database ("SELECT user WHERE username = ?"), gets back a "user record", and checks the password hash itself ("verify password hash"). If the credentials check out, the Auth Service tells the Web Server "auth token", and the Web Server tells the Client "200 OK + session token". If they don't check out, the Auth Service instead tells the Web Server "authentication failed", and the Web Server tells the Client "401 Unauthorized".
