This system ends with a User seeing ranked search results, but building the index that makes that possible happens on a separate track. On the indexing side, the Crawler Service fetches documents from the Content Store and sends the raw content to the Parser Service, which extracts text and hands it to the Tokenizer. The Tokenizer emits tokens to the Index Builder, which writes the finished index into the Search Index. On the query side, everything starts when the User submits a search query to the Query Service. The Query Service looks up matching terms in the Search Index, which returns matches to the Ranking Service; the Ranking Service returns its ranked results back to the Query Service, which finally displays the results to the User.
