Six components make up this system: Sender, Chat Service, Message Queue, Presence Service, Push Notification Service, and Recipient Device. The Sender talks only to the Chat Service, sending a message and later receiving a delivery receipt. The Chat Service talks to four others: it sends the message to the Message Queue to enqueue, asks the Presence Service for the recipient's status (getting back "recipient offline"), tells the Push Notification Service to send a push (getting back "notification queued"), and finally receives "message delivered" from the Message Queue before relaying the receipt to the Sender. The Message Queue also talks to the Recipient Device directly: it delivers the message, and the Recipient Device replies with a delivery ack.
