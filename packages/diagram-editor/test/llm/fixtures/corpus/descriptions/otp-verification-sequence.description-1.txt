This sequence diagram has four participants: User, App, AuthService, and SMSGateway. The User enters a phone number into the App. The App requests an OTP from the AuthService. The AuthService sends the OTP code to the SMSGateway. The SMSGateway delivers the OTP via SMS to the User. The User enters the OTP code back into the App. The App asks the AuthService to verify the OTP. The AuthService replies to the App that the OTP is valid.
