Six parts appear in this diagram: a User, a Password Reset Request form, an Auth Service, a Reset Token Store, an Email Service, and a New Password Form. The connections: the User submits their email address to the Password Reset Request form; the Password Reset Request form requests a reset token from the Auth Service; the Auth Service stores the token in the Reset Token Store and sends a reset email via the Email Service; the Email Service delivers the reset link to the User; and the User submits a new password to the New Password Form.
