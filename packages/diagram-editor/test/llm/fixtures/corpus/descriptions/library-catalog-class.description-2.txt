At the center of activity is the Loan class (with dueDate and returnBook() members): a Member (with name and memberId fields) borrows a Loan, that Loan references a Book (which has title and isbn fields), and a Librarian (with employeeId and checkOut() members) processes the Loan. The Book itself is written by an Author (with a name field). Zooming out to the organizational structure that holds all of this: a Catalog (with a search() method) aggregates Book, a Branch (with a location field) is composed of that Catalog and also aggregates Librarian, and a Library (with name and address fields) is composed of Branch.
