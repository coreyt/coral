This network eventually gets a package into a customer's hands or, alternatively, money back into their account, with a lot happening in between. It starts when the Customer places an order through the Storefront App, which submits that order to the Order Service. From there the Order Service fans out in two directions: it checks stock with the Inventory Service, which reads and writes stock levels in the Warehouse Database, and it charges the customer through the Payment Service, which screens the transaction with the Fraud Check Service before processing the payment through the Payment Gateway. The Order Service also sends a fulfillment request to the Warehouse Management System, which assigns a pick task to the Pick and Pack Station; once the package is ready, the Pick and Pack Station hands it to the Shipping Service, which books a shipment with the Carrier API. The Carrier API returns a tracking number to the Tracking Service, which sends shipment updates to the Notification Service, and the Order Service separately sends its own order confirmation to that same Notification Service. On the returns side, the Customer can request a return through the Returns Service, which approves a refund through the Refund Service; that refund goes out via the Payment Gateway, while the Returns Service also restocks the returned item back through the Inventory Service.
