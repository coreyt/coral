Sixteen components make up this CI/CD pipeline: Developer, Source Repository, CI Server, Lint Stage, Unit Test Stage, Build Stage, Container Registry, Security Scan Stage, Integration Test Stage, Artifact Store, CD Server, Staging Environment, Manual Approval, Production Environment, Monitoring Service, and Notification Service. The connections are: the Developer pushes a commit to the Source Repository; the Source Repository triggers a webhook to the CI Server; the CI Server runs the Lint Stage; the Lint Stage, once passed, moves to the Unit Test Stage; the Unit Test Stage, once passed, moves to the Build Stage; the Build Stage pushes an image to the Container Registry and triggers the Security Scan Stage; the Security Scan Stage, once passed, moves to the Integration Test Stage; the Container Registry also pulls its image into the Integration Test Stage; the Integration Test Stage, once passed, moves to the Artifact Store; the Artifact Store triggers a deploy on the CD Server; the CD Server deploys to the Staging Environment; the Staging Environment requests promotion from Manual Approval; Manual Approval, once approved, signals the CD Server; the CD Server deploys to the Production Environment; the Production Environment reports health to the Monitoring Service; the Monitoring Service alerts the Notification Service on failure; and the CI Server separately reports status to the Notification Service.
